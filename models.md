# Model Storage Paths

Models on this machine are stored here:

```text
C:\Users\user\AppData\Local\DubPipeline\models
```

For OPUS-MT en->de, the specific path is:

```text
C:\Users\user\AppData\Local\DubPipeline\models\hf\Helsinki-NLP\opus-mt-en-de
```

Argos packages:

```text
C:\Users\user\AppData\Local\DubPipeline\models\argos
```

Temporary download files:

```text
C:\Users\user\AppData\Local\DubPipeline\models\.partial\opus_mt
```

The root path can be overridden with the `DUBPIPELINE_MODELS_ROOT` environment variable.
